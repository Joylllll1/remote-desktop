自用远程桌面 0.1.2 — Windows x64

安装包内含 Python 3.12、Tk/Tcl 和应用依赖，安装时无需联网下载组件，
也无需另外安装 Python。安装范围仅为当前用户，不需要管理员权限。

请先安装 Tailscale 并登录自己的私人网络。两台电脑都需要保持登录、
联网及唤醒；本应用控制当前已登录的桌面，不能操作 Windows 安全桌面。

安装后从开始菜单打开「自用远程桌面」。如果这台 Windows 放在家里，
请进入共享页面，选中出门用的电脑，再开始共享。随后就能在随身电脑
的连接页面里打开 Windows 桌面。需要重启后继续使用时，可在共享页
开启登录后自动共享。

卸载前，请关闭控制窗口及共享会话。可在 Windows「已安装的应用」
中卸载，或使用开始菜单里的卸载快捷方式。卸载保留你的用户配置。

本地构建版本尚未经过真实 Windows 安装、界面与输入验收，也未签名。
完整使用说明见同目录 README.md；组件版本和校验值见 build-lock.json。
